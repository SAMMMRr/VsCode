# КиноКлуб — Telegram-бот для групповых чатов

Первый работающий MVP: поиск кино в TMDB, Rich Message-карточки с постерами и действиями внутри сообщения, оценки, избранное, общий топ группы, рецензии и голосования Telegram. Данные об оценках разделены по группам; повторная оценка обновляет предыдущую.

## Что уже реализовано

- `/film Название` — показывает статус поиска, затем отправляет Rich Message-карточку фильма или сериала с постером, жанром, длительностью, рейтингом TMDB и кратким описанием.
- Внутри Rich Message доступны действия: оценка 1–10, избранное, трейлер, анонимная сводка оценок группы и похожие фильмы.
- Inline-поиск — введи `@blastmovie_bot название фильма` прямо в поле сообщения любого чата и выбери результат. Публикация содержит Rich Message-карточку с постером и теми же встроенными кнопками.
- В Rich Message кнопка «⭐ Оценить» открывает выбор оценки 1–10; после голоса средняя оценка группы пересчитывается.
- Средняя оценка группы в карточках и `/top` показана по шкале 0–10; звёзды рядом — только визуальное представление.
- В Rich Message кнопка «❤️ В избранное» переключает фильм в личном избранном.
- Кнопки трейлера, оценок участников и похожих фильмов загружают данные TMDB и показывают проверенные результаты.
- `/top` — топ фильмов в текущем чате по оценкам участников.
- `/favorites` — фильмы, добавленные в избранное, и фильмы с оценкой от 8/10 в текущем чате.
- `/random` — случайный популярный фильм.
- `/vote Название 1 | Название 2 | Название 3` — нативное голосование Telegram.
- `/review Название | текст` — сохраняет и публикует рецензию.
- `/help` — список команд.

Rich Message-карточки отправляются через официальный `sendRichMessage` Bot API; inline-результаты используют `InputRichMessageContent`. Inline-поиск сразу использует уже закэшированные постеры, а загрузку новых запускает в фоне, чтобы не задерживать ответ Telegram; такие изображения будут доступны в карточках при следующих поисках. Для загрузки используется IPv4-соединение с CDN изображений TMDB. Бот сохраняет Telegram `file_id` в SQLite и использует его при следующих поисках. Если путь постера возвращает 404, бот запрашивает список альтернативных постеров фильма или сериала у TMDB и проверяет изображения по очереди. Если прямая загрузка не удалась, бот также пробует URL TMDB и при необходимости повторяет отправку по одному файлу. Inline-результаты используют TMDB-постер как миниатюру. Детали фильмов запрашиваются в пределах короткого таймаута; при задержке TMDB выдаются базовые результаты поиска, а запрос inline не удерживается до истечения срока. Оценки и сводка участников inline-карточки хранятся отдельно в контексте беседы Telegram, поскольку callback inline-сообщения не передаёт боту числовой chat ID. Избранное inline-публикации личное и доступно в `/favorites`.

## 1. Создать бота

1. Открой Telegram и найди `@BotFather`.
2. Отправь `/newbot`, задай название и username.
3. Скопируй выданный токен. Не публикуй его в GitHub и не отправляй в чат.
4. Добавь бота в нужную Telegram-группу. Команды `/film`, `/top`, `/vote` и другие работают в группах.

## 2. Получить доступ к TMDB

Создай/используй аккаунт на https://www.themoviedb.org/, открой настройки профиля → API и запроси API Read Access Token. В этом проекте нужен именно TMDB Bearer token, не токен Telegram.

## 3. Включить inline-поиск в Telegram

1. Открой `@BotFather` и отправь `/setinline`.
2. Выбери своего бота и задай подсказку, например `Поиск фильмов`.
3. В любом чате начни вводить `@blastmovie_bot Интерстеллар`, затем выбери нужный результат.

Без включения inline-режима через BotFather Telegram не будет отправлять боту поисковые запросы. Для работы поиска бот должен быть запущен, а в `.env` должен быть указан действующий `TMDB_READ_ACCESS_TOKEN`.

TMDB `/search/multi`, используемый inline-поиском, не возвращает названия жанров и длительность. Поэтому бот дополнительно загружает подробности каждого результата через `/movie/{id}` или `/tv/{id}`; для сериалов отображается длительность эпизода. Если запрос деталей временно недоступен, карточка всё равно публикуется с доступной информацией из поиска.

Для показа постеров в выбранных inline-карточках создай приватный канал, добавь бота администратором с правом публиковать сообщения и отправь в канале `/chatid`. Укажи ответ в `.env` как `BOT_MEDIA_CACHE_CHAT_ID=-100...`. Оставляй загруженные изображения в канале: бот хранит их `file_id` в SQLite и переиспользует при публикации и обновлении карточек.

## 4. Запуск локально в Windows

Установи Python 3.12+ и выполни в PowerShell в папке проекта:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
python bot.py
```

В `.env` замени `BOT_TOKEN` и `TMDB_READ_ACCESS_TOKEN` на свои значения. Не оставляй `replace_me`.

## Как добавить в GitHub

Создай пустой репозиторий, например `kinoklub-telegram-bot`, затем из папки проекта:

```bash
git init
git add .
git commit -m "Initial KinoKlub Telegram bot MVP"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/kinoklub-telegram-bot.git
git push -u origin main
```

Перед `git add` проверь, что `.env` не попал в индекс. В репозиторий добавляй только `.env.example`, никогда не настоящий `.env`.

## Текущие ограничения MVP

- Это групповой бот с Rich Message-карточками, а не Telegram Mini App с полноценным каталогом. Mini App можно добавить следующим этапом после теста базового сценария.
- Rich Message-карточки с постерами и кнопками поддерживаются в `/film`, `/random` и при выборе результата inline-поиска. Inline-оценки не входят в `/top` обычной группы: Telegram не сообщает числовой ID чата для inline-сообщения.
- Поиск возвращает наиболее релевантный результат TMDB; выбор из нескольких совпадений и расширенные фильтры — следующий шаг.
- `/random` предлагает популярные фильмы, а не персонализированную рекомендацию.
- Синхронное управление воспроизведением Lampa/Plex не реализовано: для этого нужна отдельная совместимая интеграция с плеером.
- Данные хранятся в локальной SQLite. Для постоянной работы регулярно создавай резервные копии файла базы.
